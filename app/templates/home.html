Therapeutic PETase Design

PANTS mines metagenomic sequence space for PET-degrading enzymes and ranks them on axes that matter at 37 °C in serum, not at 70 °C in a reactor.

Read the Methods page before using any score. {{ counts.evidenced }} of {{ counts.positives }} positives carry experimental evidence, mostly from PAZy, where an enzyme is listed because activity was measured and published. Trained on those alone the activity head reaches AUC 0.976 across 45 independent sequence clusters, against 0.829 for a composition-only baseline. Trained on the similarity-annotated remainder it reaches 1.000, which is not a better result but a circular one.

Known and characterised enzymes

Every named PETase and polyesterase in the reference set, grouped by lineage with each wild type heading the variants built on it. Read down the Topt column within a lineage and the pattern is the one that motivates this project: engineering runs away from 37 °C, the therapeutic target, which is marked on every row at or below it. Each row opens a page carrying its structure, active-site geometry, mutation set, measured activity and every external identifier.

%ID is against the wild type at the root of that enzyme's own lineage, not against IsPETase: LCC-ICCG is 98.6% identical to LCC and only about 50% to IsPETase, and only the first says how far engineering moved it. Wild types are 100% by definition. Optimum temperatures come from UniProt where an experimental value is curated and from the literature review otherwise; each enzyme page shows which, with its evidence code. Where a value is published as a range the table shows the midpoint and the page shows the range. Cleft width is measured on the structure named in the Structure column, so it mixes crystal structures with predictions; the page says which for each.
